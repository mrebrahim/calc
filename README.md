# مصاريفي — Masarify

تطبيق تتبّع مصاريف عربي (RTL) للسوق المصري. **React Native + Expo SDK 57**، تخزين محلي بالكامل
مع مزامنة اختيارية على **Supabase** — من غير أي شاشة تسجيل دخول.

مبني على الـ PRD في [`docs/PRD.md`](docs/PRD.md).

---

## المبدأ الأساسي

> المشكلة مش إن الناس مش عارفة بتصرف كام. المشكلة إنها مش بتفضل تسجّل.

كل قرار هندسي هنا راجع للمبدأ ده: التطبيق بيفتح من الداتابيز المحلية قبل أي طلب شبكة،
تسجيل المصروف لوحة أرقام بتفتح فورًا بتصنيف متقترح، والمزامنة بتحصل في الخلفية ومش بتوقف حاجة.

## المعمارية

```
app/                    شاشات expo-router
  _layout.tsx           RTL + القفل البيومتري + AppProvider
  onboarding.tsx        شاشتين، الاتنين قابلين للتخطي
  add.tsx               إضافة مصروف (modal)
  recurring.tsx         المصاريف المتكررة (modal)
  (tabs)/               الرئيسية · التقارير · الميزانيات · الإعدادات

src/

  sync/                 Supabase client + محرك المزامنة push/pull
  lib/                  حسابات المتاح اليومي، التقرير الأسبوعي، الميزانيات، الفلوس، التواريخ
  notifications/        التقرير الأسبوعي + تنبيهات الميزانية
  state/AppContext.tsx  الإقلاع، إعادة الحساب، المزامنة عند العودة للتطبيق
  i18n/                 نصوص عربية + تنسيق أرقام وتواريخ

supabase/migrations/    نفس الـ SQL المطبّق على المشروع
```

### الفلوس

كل المبالغ بتتخزن **integer بالقروش** (minor units) في SQLite و Postgres.
مفيش `float` بيلمس أي رصيد. `src/lib/money.ts` هي نقطة التحويل الوحيدة.

### المتاح اليومي — قلب التطبيق

`src/lib/allowance.ts`:

```
البركة   = المرتب + أي دخل مسجّل في الدورة الحالية
الباقي   = البركة − المصروف في الدورة − المتكرر اللي لسه هيتخصم قبل المرتب الجاي
المتاح/يوم = الباقي ÷ الأيام لحد المرتب الجاي
المتاح النهاردة = المتاح/يوم − مصروف النهاردة
```

الدورة بتبدأ من **يوم نزول المرتب**، مش من أول الشهر — ولو اليوم مش موجود في الشهر
(31 في فبراير) بيتقصّ لآخر يوم. التقرير الشهري بيمشي على نفس الدورة.

### المزامنة بدون تسجيل دخول

مفيش شاشة login في التطبيق كله. أول تشغيل بيعمل **anonymous sign-in** على Supabase،
والـ `auth.uid()` الناتج هو اللي كل صفوف الـ RLS متربوطة بيه.

- كل صف بيتعمل على الجهاز بـ UUID محلي، فالإنشاء بيشتغل offline.
- `dirty = 1` يعني فيه تعديل لسه متبعتش. الـ push بيبعته وبياخد `updated_at` بتاع السيرفر.
- الـ pull بيجيب اللي اتغير بعد آخر cursor، وبيسيب أي صف عليه تعديل محلي لسه متبعتش.
- الحذف tombstone (`deleted_at`) مش حذف فعلي، عشان الأجهزة التانية تعرف.
- التصنيفات الافتراضية بتتزرع محليًا بـ `slug` ثابت؛ لو جهازين زرعوها بـ id مختلف،
  `reconcileCategorySlugs()` بيوحّدهم قبل أول push.

فشل المزامنة **مش خطأ قاتل** — الداتابيز المحلية هي مصدر الحقيقة والتطبيق بيكمل شغل عادي.

### الخصوصية

مفيش إيميل ولا موبايل ولا حساب. الرقم الوحيد اللي بيربط الجهاز بالسيرفر هو
معرّف مجهول اتولد على الجهاز. RLS متأكّد إن كل مستخدم بيشوف صفوفه هو بس
(متحقّق منه بـ SQL: صاحب الصف بيشوف 1، غيره بيشوف 0، والكتابة باسم مستخدم تاني بترفض).

## التشغيل

```bash
npm install
cp .env.example .env      # قيم Supabase — publishable, مش سرية
npx expo start
```

### إعداد Supabase

المشروع متظبط بالفعل والـ migrations متطبّقة. لو بتظبط مشروع جديد:

```bash
supabase db push          # يطبّق supabase/migrations/
```

**خطوة مطلوبة في الداشبورد:** فعّل *Authentication → Sign In / Providers → Anonymous sign-ins*.
من غيرها المزامنة هتفضل `offline` والتطبيق هيشتغل محلي بس (وده مقبول — بس مفيش نسخة احتياطية).

المفتاحين في `.env.example` **publishable** بطبيعتهم ومصمّمين يتشحنوا جوه التطبيق؛
الحماية الفعلية من RLS مش من إخفاء المفتاح.

### فحص

```bash
npx tsc --noEmit                          # types
npx expo export --platform android        # يتأكد إن كل حاجة بتتباندل
```

### البناء (Codemagic)

`codemagic.yaml` فيه 4 workflows:

| Workflow | بيطلّع إيه | محتاج إيه |
| --- | --- | --- |
| `android-debug-signed` | APK للتجربة | مفيش — يشتغل على طول |
| `android-play-store` | AAB موقّع | keystore مرفوع باسم `masarify_keystore` |
| `ios-testflight` | IPA | حساب Apple Developer مربوط بـ Codemagic |
| `pr-checks` | typecheck + bundle | مفيش |

الـ `android/` و `ios/` **مش مرفوعين** في الريبو (مشروع Expo managed)، فكل workflow
بيعمل `expo prebuild` الأول. لازم كمان تضيف group اسمه `supabase` في
Environment variables فيه `EXPO_PUBLIC_SUPABASE_URL` و `EXPO_PUBLIC_SUPABASE_KEY`.

## مؤجّل (v1.1+)

قراءة رسائل البنوك (SMS — أندرويد فقط)، الإدخال الصوتي بالعامية، OCR للفواتير،
تتبّع الديون والأهداف (الجداول موجودة، الشاشات لأ)، تعدد العملات، الملخص الذكي، اشتراك Pro.

`is_pro` موجود في الإعدادات وسقف الميزانيات المجاني (تصنيفين) مطبّق بالفعل،
بس مفيش ربط دفع لسه — الـ PRD بيقول ما تبنيش الدفع قبل ما تثبت الاحتفاظ.
